# Инструкция по размещению спрайт-листа

## 📁 Структура папок

Создайте следующую структуру папок в вашем проекте:

```
public/
  └── sprites/
      └── player_spritesheet.png
```

## 🖼️ Размещение вашего спрайт-листа

1. **Создайте папку** `public/sprites/` в корне вашего проекта

2. **Поместите ваш спрайт-лист** в эту папку с именем `player_spritesheet.png`

3. **Или используйте сгенерированный пример**:
   - Скачайте изображение по ссылке: https://image.qwenlm.ai/generated-images/278658ac-130a-4ad6-822b-8c493525fe32/_result.png
   - Сохраните его как `public/sprites/player_spritesheet.png`

## ⚙️ Настройка конфигурации

После размещения файла, откройте `src/game/SpriteConfig.ts` и убедитесь, что параметры соответствуют вашему спрайт-листу:

```typescript
const spriteSheet = new SpriteSheet(
  '/sprites/player_spritesheet.png', // Путь к файлу
  64,  // Ширина кадра (измените если нужно)
  64,  // Высота кадра (измените если нужно)
  8,   // Количество колонок (измените если нужно)
  8    // Количество строк (измените если нужно)
);
```

## 🎬 Настройка анимаций

Пример конфигурации для спрайт-листа 8×8:

```typescript
// Idle: строка 0, кадры 0-3
spriteSheet.addAnimation('idle', 0, 3, 8, true);

// Run: строка 1, кадры 8-15
spriteSheet.addAnimation('run', 8, 15, 12, true);

// Jump: строка 2, кадры 16-17
spriteSheet.addAnimation('jump', 16, 17, 8, false);

// Fall: строка 2, кадры 18-19
spriteSheet.addAnimation('fall', 18, 19, 8, false);

// Climb: строка 2, кадры 20-23
spriteSheet.addAnimation('climb', 20, 23, 8, true);

// Attack Melee: строка 3, кадры 24-27
spriteSheet.addAnimation('attack_melee', 24, 27, 15, false);

// Attack Shoot: строка 3, кадры 28-31
spriteSheet.addAnimation('attack_shoot', 28, 31, 12, false);

// Hurt: строка 4, кадры 32-35
spriteSheet.addAnimation('hurt', 32, 35, 10, false);

// Death: строка 5, кадры 40-45
spriteSheet.addAnimation('death', 40, 45, 8, false);
```

## 🧪 Тестирование

1. Запустите проект: `npm run dev`
2. Откройте игру в браузере
3. Проверьте консоль (F12) на наличие сообщений:
   - "Sprite sheet loaded: /sprites/player_spritesheet.png"
4. Персонаж должен отображаться с использованием спрайт-листа

## 🔄 Fallback режим

Если спрайт-лист не загружается, игра автоматически переключится на процедурную отрисовку (старый метод). Это нормально для тестирования.

## 📝 Примечания

- Путь к файлу должен начинаться с `/sprites/` (без `public/`)
- Файл должен быть в формате PNG с прозрачностью
- Все кадры должны быть одинакового размера
- Рекомендуется использовать размер кадра 64×64 или 128×128 пикселей

## 🐛 Решение проблем

### Спрайт не загружается
- Проверьте, что файл находится в `public/sprites/`
- Убедитесь, что имя файла точно `player_spritesheet.png`
- Проверьте консоль браузера на ошибки

### Анимации отображаются неправильно
- Проверьте, что `columns` и `rows` указаны правильно
- Убедитесь, что номера кадров соответствуют вашей сетке
- Проверьте, что размер кадра указан правильно

### Размеры не совпадают
- Измените `frameWidth` и `frameHeight` в конфигурации
- Убедитесь, что все кадры одинакового размера
- Проверьте, что hitbox игрока соответствует размеру спрайта
